# EECE-5644-miniproject-03
## Overview
This project runs and analyzes a small GPT model with a 2-layer 64-embedding dimension transformer. The model is trained with a list of questions and answers about machine learning from the file [ml_textbook.txt](ml_textbook.txt). The outputs from the model are used to answer a series of questions about predictive text models and how their inputs and structure affect them.

## Running the Notebook

The requirements in [requirements.txt](requirements.txt) must be installed. They can be installed by running
```
pip install -r requirements.txt
```

This will allow the user to run the jupyter notebook [Quiz_GPT_03.ipynb](Quiz_GPT_03.ipynb) which contains the model and questions.
